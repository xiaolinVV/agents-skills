# Playwright Gitee Checklist

## 登录与会话

- 登录失效时走短信登录：
  1. 选择短信登录
  2. 输入手机号 `15505903237`
  3. 点击“获取验证码”
  4. 向用户索取验证码
  5. 输入验证码并继续

## Mode A: framework-source（原流程）

目标：从 `jeecg-boot_3` 初始化后，创建业务组织与业务仓库。

步骤：
1. 打开 `https://gitee.com/organizations/jeecg-boot_3/projects`。
2. 确认需克隆仓库存在（默认 5 仓）。
3. Gate 2 通过后，在用户账号下创建业务组织。
4. 在业务组织下创建仓库（默认私有）。

失败回退：
- 组织名冲突：提示用户改名重试。
- 权限不足：停止远程创建步骤，保留本地状态。

## Mode B: user-source（新增）

目标：从用户所选组织直接克隆，不创建新组织。

步骤：
1. 打开用户账号可见的组织列表页。
2. 提取并列出全部组织名称供用户选择。
3. 用户选定 `source_org` 后，仅验证该组织仓库存在性。
4. 不执行组织创建，不执行仓库创建。

失败回退：
- 组织列表为空：提示用户检查账号权限或登录状态。
- 组织存在但仓库缺失：记录缺失仓库并提示用户补仓后重试。

## Git SSH 约束

- 克隆与 remote 配置必须使用 SSH URL：`git@gitee.com:<org>/<repo>.git`
- SSH 认证失败时，立即中止流程，输出修复建议：
  - `ssh -T git@gitee.com`
  - `ssh-add -l`
- 禁止自动回退 HTTPS，避免交互中途再次触发认证中断。

## 稳定性建议

- 优先按可访问名称定位控件（按钮文案、输入框 label）。
- 每次点击后等待关键文本出现再继续。
- 远程创建类动作只在 framework-source Gate 2 后执行。
