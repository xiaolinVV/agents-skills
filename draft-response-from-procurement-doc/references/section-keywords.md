# Section Keywords for Procurement Documents

Never search by chapter number first. Search by meaning.

## 1. Response-template section
Look for headings or nearby phrases such as:
- 响应文件格式
- 投标文件格式
- 应答文件格式
- 参选文件格式
- 报价文件格式
- 响应文件组成
- 投标文件组成
- 附件：响应文件模板
- 附件：格式
- 附件：报价表

What to extract:
- required file split (报价部分 / 技术商务部分 / 资格部分 / 商务部分 / 技术部分)
- required section order
- mandatory forms and tables
- whether deviation tables may be replaced by commitment letters
- whether first quote / second quote / negotiation quote has a separate format

## 2. Qualification and submission rules
Look for:
- 投标人须知 / 供应商须知 / 报价人须知 / 参选人须知
- 前附表
- 资格条件 / 合格的供应商
- 保证金 / 履约保证金 / 响应有效期
- 递交地点 / 截止时间 / 密封 / 装订 / 盖章 / 正本 / 副本

What to extract:
- who may bid
- required qualification attachments
- whether joint venture is allowed
- response validity period
- submission address and deadline
- sealing / binding / stamping rules
- bid bond and payment account

## 3. Technical and commercial requirements
Look for:
- 项目概况
- 采购需求 / 项目需求 / 招标内容及要求 / 征集内容及需求
- 技术要求 / 技术和服务要求
- 商务要求
- 服务要求 / 交付要求 / 验收要求

What to extract:
- package / lot scope
- module list, quantities, workload, or service period
- delivery time and place
- acceptance rules
- warranty / support / training
- payment milestones
- no-negative-deviation clauses

## 4. Contract and risk terms
Look for:
- 合同模板 / 合同条款 / 采购合同 / 商务合同 / 主要合同条款
- 知识产权 / 保密 / 违约责任 / 源代码 / 验收 / 试运行 / 变更

What to extract for user warning:
- IP ownership transfer
- source-code handover
- prohibition on encryption or license expiry
- broad change-scope obligations without extra payment
- liquidated damages and unilateral termination rights
- long holdback payment terms

## 5. Price-round documents and sample files
Look for filenames and headings such as:
- 一次报价单 / 报价表
- 二次报价单 / 谈判报价表
- 最终报价 / 最后报价
- 技术商务部分
- 商务部分 / 技术部分

Use them to:
- confirm package-specific structure
- extract exact prices and tax rate
- detect first-round vs second-round file split

Do not trust them for:
- dates
- company contact details
- chapter numbers
- copied package numbers
- copied service names
