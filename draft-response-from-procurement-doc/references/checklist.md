# Procurement Response Drafting Checklist

## A. Extraction checklist
Before drafting, extract and record:
- project name
- project number
- purchaser / procuring entity
- package / lot number
- package name
- submission deadline
- response validity period
- bond amount and payment account
- submission address and recipient
- original / copy / electronic submission rules
- sealing / binding / stamping rules
- qualification attachments
- technical scope
- commercial requirements
- payment terms
- acceptance terms
- contract-risk notes

## B. Template-mapping checklist
Confirm from the source template:
- exact file split required
- exact section names required
- whether quotation and technical-business sections must be separated
- whether deviation tables can be replaced by commitment letters
- whether negotiation quote has a dedicated form

## C. Drafting checklist
When drafting:
- use the source procurement document as the main authority
- use sample files only as secondary references
- preserve the buyer's required section order
- keep wording plain and compliant
- use placeholders instead of invented company facts
- explicitly note the price source file when multiple quote files exist

## D. Consistency checklist
Check these before delivery:
- package number consistent everywhere
- service name consistent everywhere
- project name consistent everywhere
- amount in figures = amount in words
- tax rate consistent everywhere
- first quote vs second quote files not mixed up
- dates consistent within each file
- signature and seal positions present

## E. Qualification checklist
Verify whether the draft and checklist cover:
- business license
- legal representative ID
- authorized representative ID
- power of attorney
- no-major-illegal-record statement
- credit screenshots
- execution-information screenshots
- any extra qualification files required by the source document

## F. Risk-review checklist
Warn the user if the contract includes:
- source-code handover
- full IP transfer
- no-encryption/no-expiry restrictions
- unpaid change requests bundled into total price
- harsh penalties or unilateral termination
- long retention / holdback payment
- strict on-site support obligations

## G. Final delivery checklist
Deliver:
- drafted response file(s)
- drafted price file(s)
- missing-information checklist
- short note explaining which price source file was used
- short risk summary if the contract terms are unusually aggressive
